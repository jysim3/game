# Jigsaur logo

Rendered from the app launch animation
(`apps/mobile/src/assets/animations/jigsaur-logo.json`, final frame 134 of the Lottie)
with lottie-web's SVG renderer in headless Chromium on 2026-09-18.

| File | Contents |
| --- | --- |
| `jigsaur-logo-full.svg` | Mark + `jigsaur.app` wordmark, vector |
| `jigsaur-logo-full-transparent.png` | Same, 3048x3108, transparent background |
| `jigsaur-logo-full-white.png` | Same, 3048x3108, white background |
| `jigsaur-logo-mark.svg` | Mark only (wordmark layer removed), vector |
| `jigsaur-logo-mark-transparent.png` | Same, 2360x2360, transparent background |
| `jigsaur-logo-mark-white.png` | Same, 2360x2360, white background |

Notes

- The wordmark is outlined paths in the animation, so no font is needed.
- The shuttlecock is an embedded 95x105 raster PNG in the source Lottie; it is
  the only non-vector element and will look soft at very large sizes.
- Padding around the artwork is 6% of the longer side.
